# Cursor AI Setup & Workflow Exploration

## Overview

This repository documents my process of setting up a modern AI-assisted development environment using Cursor IDE, along with Claude and Codex extensions.

The goal of this project is not only to complete the setup, but also to explore how AI tools can enhance productivity, problem-solving, and learning speed in a real development workflow.

---

## Tools & Technologies

* **Cursor IDE** – AI-powered code editor
* **Claude Code Extension** – AI assistant for reasoning and structured responses
* **Codex Extension** – AI-assisted code generation
* **Git & GitHub** – Version control and repository management

---

## Setup Process

### 1. Installing Cursor IDE

* Downloaded and installed Cursor from the official website
* The installation process was smooth, as I am already familiar with working in text editors and development environments

### 2. Installing AI Extensions

* Installed **Claude Code** and **Codex** via Extensions panel
* Logged into both services successfully

### 3. Handling Login Behavior

* Initially expected a login popup, but it did not appear
* Used **Command Palette (Cmd/Ctrl + Shift + P)** to manually trigger authentication
* Successfully connected both extensions

### 4. GitHub Repository Setup

* Created a public repository on GitHub
* Initialized Git locally using terminal
* Connected local project to remote repository

### 5. Version Control Workflow

* Added files using `git add`
* Created commits with clear messages
* Pushed changes to GitHub

## Challenges & Problem Solving

### Smooth Installation Experience

**Observation:**
The installation process did not present major issues.

**Reason:**
My prior experience using text editors and development tools helped me quickly understand the interface and setup flow.

---

### Extension Login Behavior

**Issue:**
No automatic login popup appeared after installing extensions.

**Solution:**
Used Command Palette to manually trigger login commands.
This revealed that not all tools follow expected UI patterns.

---

### GitHub Push Conflict

**Issue:**
Encountered push conflict due to existing README from GitHub initialization.

**Solution:**
Resolved using:
git pull origin main --rebase

This helped me understand how Git handles remote conflicts.

## Key Learnings

* Familiarity with development tools significantly speeds up onboarding
* AI tools are powerful, but require active exploration
* Real-world tools often behave differently than expected → adaptability matters
* Git is a workflow system, not just a tool
* Clear documentation improves communication and understanding

## Reflections

This process reinforced the importance of adaptability when working with new tools.

While the setup itself was relatively smooth, small unexpected behaviors (such as login flow differences) required exploration and problem-solving.

My approach was to:

* Stay curious and experiment
* Search for targeted solutions when needed
* Break problems into manageable steps

This helped me complete the setup efficiently while still gaining deeper understanding.
